# 测试说明

所有测试课表、教师、教室和 Excel 数据均为虚构。

## 范围

24 项单元测试覆盖教学周边界、单双周和特殊周次、Excel 解析、多组教室对应、导出重导入、空课表、课程增删改与冲突校验、默认模板不预置课程。

6 项设备测试覆盖：

1. 左右滑动翻周和首末周边界。
2. 学期设置校验、保存和 Activity 重建后的保留。
3. 特殊周次课程时间、教室详情与页面切换。
4. 从空课表通过系统文件选择器导入虚构 Excel。
5. 新增、编辑课程，以及取消删除和确认删除。
6. 空课表页面和作息配置。

设备测试恢复开始前的课表和学期设置，成功后移除测试辅助包。
